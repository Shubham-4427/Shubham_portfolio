## 💻 Run Locally

### Prerequisites

- Node.js **20.19+** or **22.12+** recommended
- npm
- Git

### Setup

1. Clone the repository:

   ```bash
   git clone https://github.com/Shubham-4427/Shubham_portfolio.git
   cd Shubham_portfolio
   ```

2. Install dependencies:

   ```bash
   npm install
   ```

3. Start the development server:

   ```bash
   npm run dev
   ```

4. Open the local URL printed by Vite, usually http://localhost:5173.

### Production build

Build the site and preview the production output locally:

```bash
npm run build
npm run preview
```

Vite outputs the production files to the `dist/` directory.

## ⚙️ Customize

To update portfolio content, edit `src/App.jsx`. The profile details are defined in the `profile` object, while featured and selected project links and descriptions are configured in the project components and `projects` array.

Before publishing your own changes, check that contact details, project URLs, and descriptions are accurate.
